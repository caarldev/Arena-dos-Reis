# Arena Real
Jogo estilo Clash Royale em Python + Kivy.

## Gerar o APK
1. Suba todos os arquivos deste ZIP para um repositório no GitHub.
2. Abra a aba **Actions** > **Build APK** > **Run workflow** (também roda sozinho a cada push).
3. Quando terminar (~20-30 min na 1ª vez), baixe o APK em **Artifacts**.

## Testar no PC
pip install kivy pillow && python main.py

## Como jogar
Toque numa carta e depois na sua metade da arena. A Bola de Fogo pode ir em qualquer lugar.
Derrube a torre do Rei inimigo ou tenha mais torres derrubadas quando o tempo acabar.
